# Building Better Organizations

A simple static GitHub Pages site that organizes the Team Health Assessment, OLIA, Observation Journal, Writing and Observations, and Connect with Me.

## Included
- `index.html` — homepage
- `pages/` — five section pages
- `assets/style.css` — responsive styling

## Links currently configured
- LinkedIn: https://www.linkedin.com/in/chris-clause-phd-4a120318
- Substack: https://substack.com/@buildingbetterorganizations
- Existing OLIA assessment: https://cclause33.github.io/organizational-learning-infrastructure/

The Team Health Assessment page is an introduction/placeholder until you choose the assessment URL or format to publish. The Observation Journal page provides prompts only; it does not store entries.

## Publish using GitHub Pages
1. Create a new public repository named `cclause33.github.io` (if it does not already exist).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside an extra nested folder.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the GitHub Pages deployment to finish and open `https://cclause33.github.io/`.

Do not upload these files into the existing `organizational-learning-infrastructure` repository, because that would replace or mix with the OLIA project. Keep the main site in its own repository.

## Editing content
Edit the relevant `.html` page through GitHub's web editor. Keep the same page structure and update text or links. Styling is centralized in `assets/style.css`.
